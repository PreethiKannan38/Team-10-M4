# JSON Import Feature

This feature allows users to import a previously exported JSON file to restore their canvas state.

## Functionality
- **Import Button**: Located in the top bar.
- **File Support**: Accepts `.json` files generated by the "Export JSON" feature.
- **State Restoration**: Reconstructs layers, objects, and layer order from the JSON data.
- **View Reset**: Automatically resets pan and zoom to fit the content (default view).

## Usage
1. Click the "Download" icon in the top right.
2. Select "JSON (Upload Project)".
3. Choose a valid JSON file.
4. The canvas will clear and reload with the imported data.

## Implementation Details
- Uses `FileReader` to parse client-side files.
- Updates Yjs shared types (`yMap` for objects, `yArray` for layers) within a transaction.
- Includes error handling and validation for JSON structure.
